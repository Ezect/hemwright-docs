Hemwright documentation

Hemwright is an editorial Online Store 2.0 theme for fashion and apparel stores. This guide covers installation, the main sections, theme settings, home page setup, images, languages and common questions. Version 1.0.0.

Installation

Option A: upload a zip

  1. In the Shopify admin go to Online Store > Themes.
  2. Click Add theme > Upload zip file and choose the Hemwright zip.
  3. Click Customize on the uploaded theme to edit it, or Publish when you are ready.

Option B: Shopify CLI

  1. Install Shopify CLI.
  2. In the theme folder run shopify theme dev --store your-store.myshopify.com to preview, or shopify theme push to upload.

After installing

  • Set a logo and favicon in Theme settings > Logo.
  • Create menus in Content > Menus (a main menu and a footer menu) and pick them in the Header and Footer sections.
  • Create the pages you need (About, Contact, FAQ, size guide). Hemwright includes page templates named page.about, page.contact and page.faq.
  • Add products and collections. 3D models are optional.

Tip: duplicate your live theme (Actions > Duplicate) before you try something new, so you can always go back.

Main sections

Open Online Store > Themes > Customize. Use the page selector at the top to move between Home, Product, Collection, Cart, Blog, Search and other pages. On every page you can add, remove and reorder sections; each section has its own settings and blocks. The header and footer are shared by all pages. Settings that apply everywhere are in Theme settings.

Presets and theme settings

The Theme Store version of Hemwright includes one preset, named Hemwright: a warm paper background, dark text and a camel accent, with Oswald headings, Inter body text and motion set to Full. A preset sets colors, fonts and motion defaults in one step. Every value can then be changed in Theme settings.

  • Logo: logo image, logo width, favicon.
  • Colors: color mode (Light, Dark, or Automatic, which follows the visitor's device) and the palette for each mode. Keep a contrast ratio of at least 4.5:1 for text colors.
  • Typography: heading and body fonts (Shopify font library), uppercase headings, heading scale, body size.
  • Layout: maximum page width (Narrow, Wide, Full width), side margin, space between sections.
  • Buttons: corner radius and button style.
  • Cards: product card image ratio, second image on hover, brand, badges.
  • Collection page: how more products load (numbered pages, "Load more" button or infinite scroll).
  • Shopping features: quick view; light/dark switch in the header.
  • Cart: cart type (Drawer or Page) and order note.
  • Social: Instagram, Facebook, TikTok, YouTube and Pinterest links. Leave empty what you do not use.

Motion effects

Under Theme settings > Motion effects:

  • Motion effects: Off (static pages, effect files are not loaded), Reduced (soft fades only) or Full (3D, parallax, scroll effects).
  • Effect intensity: Low, Medium or High. It scales angles, distances and shadows.
  • Each effect has its own switch, so you can keep the ones you like and turn off the rest.

Visitors whose device asks for reduced motion always see a static page, whatever you choose. If your store feels slow on phones, choose Reduced or intensity Low. Some effects use CSS scroll-driven animations, which work in current Chrome, Edge and Safari; in Firefox the page stays static but complete.

Customizing the home page

  1. Open Customize and select Home in the page selector.
  2. Click a section in the left panel to edit its text, images, buttons and colors. Many sections let you choose a tone (theme, light, dark or sand).
  3. Use Add section to bring in other sections from the list above. Drag sections to reorder them, or click the eye icon to hide one without deleting it.
  4. Start simple: a Hero, a Featured collection, a Brand story and a Newsletter already make a complete home page. Add effect-heavy sections one at a time and check them on your phone.
  5. Replace the example texts. Reviews, FAQ answers and similar content are placeholders for you to rewrite with your own real content.
  6. In the Announcement bar, write your own messages. To show your free shipping amount, write [amount] in a message and set the amount in Theme settings > Cart.

Use only one heavy video or 3D object above the fold. Everything else should load lazily.

Images and media

  • Alt text: write it for every image that carries meaning. For products: Products > image > Edit alt text. For images chosen in sections: Content > Files. Purely decorative images do not need it.
  • Hero and banner images: under 300 KB each, 2400 px wide at most, JPG or WebP at quality 75-80.
  • Product and collection images: under 500 KB each, 2048 px on the long side at most.
  • Hero video: under 3 MB, 10 seconds or less, H.264 MP4, no audio, around 720p on phones. Always set a poster image.
  • Text over photos: check that it stays readable; use a darker photo or a stronger overlay if needed.
  • 3D models: add a .glb file to a product (Product > Media) and keep it under 3 MB. The product page then shows a "View in 3D" button. When a product has no 3D file, a bundled demo model can optionally be shown as a preview. 3D is entirely optional.

These are recommendations to keep your store fast; the theme requests the right image size for each device.

Languages

Storefront text and theme editor labels are included in eight languages: English, Italian, German, Spanish, French, Japanese, Dutch and Portuguese (Portugal). Add languages in Settings > Languages and publish them to your markets. The language and country selector appears when you sell in more than one language or market.

Right-to-left: when the active language is Arabic, Hebrew, Persian or Urdu, the page direction switches to right-to-left. No text in those languages is bundled: add it in Online Store > Themes > Actions > Edit default theme content, or with Shopify's Translate & Adapt app. Until you do, untranslated text shows in English.

Product titles, descriptions and menus are translated in your Shopify admin, not by the theme. The theme editor uses the language of your staff account.

Frequently asked questions

Can I turn off all effects?

Yes. Go to Theme settings > Motion effects and choose Off.

Do I need 3D models?

No. 3D is optional and can be left unused.

Does Hemwright work with apps?

Yes. App blocks are supported on the product page and in many sections. Not every 3D section has app blocks.

Is the theme fast?

Speed depends on your images, apps and the effects you keep on. Measure your own store with PageSpeed Insights. Choosing Reduced or Off motion and removing unused sections helps.

Does it support back-in-stock alerts and pre-orders without apps?

Yes, within limits: back-in-stock requests arrive as emails to your store (the theme does not send an automatic message when the item returns), and a pre-order is a normal order marked as pre-order, with no advance or split payment.

How do filters work on collection pages?

Install the free Shopify Search & Discovery app and add filters (availability, price, size, color and so on).

Can I use my own fonts?

Hemwright uses the Shopify font library (the font picker). No font files are bundled.

Does it work in Arabic or Hebrew?

The layout does. The translated text is not included, so you need to add it (see Languages).

Is the theme accessible?

It is built following WCAG 2.1 AA practices and its code was reviewed against them. This is not an external certification, and the result also depends on your content: alt text, colors you choose and videos you add.

The 3D model does not appear.

Check that the file is a .glb and is attached to the product under Media. If automatic start is off, the visitor can still press "View in 3D".

Effects do not run.

Set Motion effects to Full and check the single effect switch. Devices set to reduce motion always see a static page.

The header menu is empty.

Create a menu in Content > Menus and select it in the Header section.

The cart drawer does not open.

Check that Theme settings > Cart > Cart type is set to Drawer.

My page is slow.

Use smaller images, remove sections you do not need, limit 3D objects per page and uninstall unused apps.

Where do I report a problem?

See the support page.
